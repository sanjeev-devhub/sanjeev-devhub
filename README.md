# 💫 About Me:
Hi, I'm Sanjeev Kumar 👋

I'm a Java Backend Developer with 5 years of experience designing and building scalable, enterprise-grade applications across the banking, healthcare, and retail domains. My core stack is Java (8/11/17), Spring Boot, and Quarkus, and I have deep hands-on experience with microservices, event-driven architecture, and distributed systems. A good part of my work centers on workflow automation using Camunda BPM 7, Camunda Platform 8, Zeebe, and BPMN 2.0 — turning complex business processes into reliable, automated flows. I build and optimize REST and GraphQL APIs with a focus on low latency and scalability, and I deploy cloud-native on AWS using Docker and Kubernetes. I also work across Kafka, Redis, PostgreSQL, and Oracle, and care a lot about observability, performance tuning, and production reliability, backed by solid testing practices (JUnit, Mockito, SonarQube, 90%+ coverage). Always keen to build clean, maintainable systems that scale.
