# 💫 About Me:
I am a backend-focused software developer with a strong interest in building reliable, scalable, and efficient systems. I enjoy working with Java and modern frameworks such as Spring Boot, Quarkus, and Hibernate to design clean APIs, develop microservices, and solve complex business problems through well-structured code. I have hands-on experience with technologies like Kafka for messaging, Camunda BPM for workflow automation, and GraphQL and REST for API development. I am particularly interested in cloud-native development using AWS and Azure, along with containerization and orchestration tools like Docker and Kubernetes. I continuously explore new tools and technologies to improve the way systems are built and deployed. I value clean architecture, code quality with practices using JUnit, Mockito, and SonarQube, and thoughtful problem-solving, striving to create solutions that are robust, maintainable, and future-ready.
